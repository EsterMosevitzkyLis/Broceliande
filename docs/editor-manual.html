Map Editor Manual

How to edit Broceliande's battle maps: lanes, the Druid and sectors, candidate spots, decoration, mire, palette and background. Each level's ground lives in its own file, data/maps/<level>.json. The numbers (waves, step budget, feature mix, quotas) stay in the Google Sheet.

1. Starting the editor

From the project folder, run python tools/serve.py and open http://localhost:8000/editor.html in Chrome. Saving only works through this server, and only from your own computer: it writes nothing but data/maps/<level>.json.

Pick a level in the drop-down at the top. The editor remembers the last one, and editor.html?level=<id> opens a given level. If a level has no map file yet, it opens as a blank map; use Generate draft for a starting point, then Save.

Save (Ctrl+S) writes the file. Saving an unchanged level writes exactly the same bytes. The dot next to Save shows unsaved changes, and the browser warns before you leave with any.

2. The screen

  • Top bar: level picker, Save, Undo, Redo, Preview a run, Play this level (with a "debug resources" box), Generate draft, and a status line.
  • Left: the tools: Select, Lanes, Druid, Spots, Place, Scatter, Mire, Palette, Background.
  • Centre: the map, drawn as the game draws it, with editing overlays.
  • Right panel (scrolls):
    • the tool's help and options;
    • the selection, with typed x and y;
    • the Level section: corridor width, sectors, Level rules;
    • Zone rules (Druid and Spots tools);
    • Level data;
    • layer toggles and snap;
    • the checks list.

Layers: ground, lanes, mire, decoration, spots, zones, checks, and lane labels. They only change what you see, never the file. Some overlays show anyway with their tool: lanes and lane labels with the Lanes tool, zones with the Druid tool, spots with the Spots tool.

3. Selection, undo and snap

  • Select: click a spot, the Druid or a decoration object. Drag empty ground to box-select; Shift adds to the selection. Dragging a selected object moves the whole selection.
  • Typed coordinates: with one spot, the Druid, a waypoint or a decoration object selected, type its x or y in the right panel. Each typed value is one undo step. Moving the Druid this way moves the lane ends with him, as dragging does.
  • Undo and redo: Ctrl+Z and Ctrl+Y (or Ctrl+Shift+Z). Each drag, brush stroke, typed value or button is one step, and up to 200 steps are kept per level.
  • Snap to grid: off, 10 or 20 px. The object you grab snaps; the rest of the selection keeps its offset.
  • Everywhere: Delete removes the selection, the arrow keys nudge 1 px (10 px with Shift), and Esc deselects.

4. Lanes tool L

A level has 1 to 4 lanes. Each lane is a list of waypoints, from its entry point (just off screen) to the Druid's melee ring. The game smooths the waypoints into a curve.

  • Move a waypoint: drag it. Box-drag selects several waypoints.
  • Insert a waypoint: click a corridor.
  • Delete a waypoint: select it and press Delete. A lane keeps at least 2 waypoints.
  • Lane labels: each lane's id shows at its entrance. This is the name the sheet's spawns rows use.

The lanes table

The Tool section lists every lane with its id, its name, and the waves that spawn on it (for example "38 enemies in waves 1, 2, 3"). You can edit the id and the name there.

Renaming a lane id breaks every spawns row that names the old id. The checks list those rows as errors until the sheet uses the new id.

New lane

  1. Click New lane. The button turns into "Cancel new lane"; Esc also cancels.
  2. Move the pointer over the map. A ring marks the entry point on the nearest screen edge, and a dashed line runs to the Druid.
  3. Click. The lane enters 40 px beyond that edge and winds to the Druid's melee ring, about LANE_LENGTH_FACTOR times the straight distance long (the same generator Generate draft uses).

A new lane gets its id and name from its direction from the Druid, e.g. south / "South", with a number added if that id is taken. Rename it in the lanes table if you like. Reshape it with the waypoints as usual. Any mire under the new corridor is cleared.

New lane is greyed out at 4 lanes.

Delete lane

Click Delete on a lane's row. The editor asks first. If the level's waves spawn on that lane, the question says how many enemies and in which waves: those spawns rows become errors until you move them to another lane (or random) in the sheet. The last remaining lane can't be deleted.

Adding or deleting a lane never changes the sectors or zones (see the next section).

The sheet's lanes tab lists each level's lane ids for the spawns drop-down. After you add, delete or rename a lane, the checks show the rows the lanes tab should have, ready to paste. The check only runs for levels that already have rows in the lanes tab.

5. Druid tool and sectors D

The Druid tool shows the zones.

  • Move the Druid: drag him. Each lane's last waypoint follows him.
  • Turn a sector boundary: drag its white handle. Boundaries keep their order round the Druid, at least 5° apart.
  • Resize the near ring: drag it.

Sectors and zones

The ground round the Druid is split into sectors, and the near ring splits each sector into a near and a far zone. A sector named SW, for example, gives zones nSW and fSW. Zones decide where turret slots and resource spots are rolled each run (see Zone rules).

Sectors belong to the map, not to the lanes. Every existing level has 3, and a new level starts with 3. Use the − and + buttons in the Tool section to change the count (1 to 6):

  • + splits the widest sector in half. The new half is named after its compass direction.
  • − merges the narrowest sector into the one anticlockwise from it, which keeps its name.
  • The other sectors keep their names, so their zones, quota overrides and manual spot zones stay as they were.
  • Spots with a manual zone in a sector that's gone go back to auto. That sector's zone quota overrides are removed.

More or fewer zones change the total number of turret slots and resource spots, so the feature mix may no longer match. The Zone rules section and the checks say so. Fix it with quota overrides here, or with the mix in the levels tab.

6. Spots tool S

Candidate spots are the places a run can put a turret slot or a resource spot, or leave empty.

  • Add: click empty ground.
  • Move: drag.
  • Remove: Delete.

Each spot is drawn with its footprint and a dashed ring for its jitter, plus its index and zone (* marks a manual zone). Select one spot to edit it:

  • Role: auto (rolled each run), turret slot, resource spot (type rolled), resource spot of a given type, not vacant (turret or resource, rolled), or vacant (always empty). Pinned spots show a badge: T, R, R:Pond, ≠∅, ∅.
    • Pins count towards their zone's quotas.
    • Pinned feature types come out of the feature mix first.
    • Pins the quotas can't honour are errors.
  • Jitter: how far (0 to 40 px) the spot's object may land from it each run. default goes back to LOCATION_JITTER. Every spacing and clearance rule uses each spot's own jitter.
  • Zone: auto (from the geometry) or a manual zone.
  • Covers: the lanes within base turret range of the spot. Dashed lines on the map show where.

7. Decoration: Place P and Scatter B

Place: pick a type and variant from the thumbnails, then click the map. Click an object to select it.

  • F flips it.
  • [ and ] scale it by 10%. Scale is a multiplier of the type's default size, also for landmarks.
  • N cycles its variant.

Greyed types need palette colours the level lacks. Picking one adds them from a level that has them.

Scatter: a brush that paints single objects from a mix, at a given radius and density. "Keep clear" keeps it off corridors, spots and the Druid's clearing. Erase removes upright objects under the brush, but never landmarks. Each stroke is one undo step.

8. Mire M

Mire is a grid of 16 px cells that slows the Druid's route (it costs more steps). Paint or erase it with the brush. It can't be painted on a corridor. Moving a lane over mire, adding a lane or widening the corridors clears the cells underneath.

9. Palette and Background

Palette: every colour the level draws with; the map updates as you pick. Copy all takes another level's palette; Add missing adds only the colours this one lacks.

Background: pick an image from data/maps/backgrounds/ (copy files there by hand). With an image set, the game draws it instead of the procedural ground. The opacity slider is for the editor only, to see the ground underneath.

10. Level, Zone rules and Level data

Level

  • Corridor width: a slider, one undo step per drag. The checks warn if a boss in the waves no longer fits.
  • Sectors: each sector's boundary angle, and the near radius.
  • Level rules:
    • the turret slots that must cover each lane (applied to every lane, however many there are);
    • the Prep route band's lower and upper edges.
    Blank means the global default, shown in grey. ↺ removes this level's own value.

Zone rules

Shown with the Druid or Spots tool. For each zone: its spots, its pinned spots, and its turret and feature quota. Type a number to override the default for this level; ↺ removes the override. The totals at the bottom warn when the resource spots don't match the feature mix.

Level data

A read-only summary of the sheet's numbers for this level:

  • region, row and node type;
  • enemyHpMult and stuckTime;
  • stepBudget with the suggested budget;
  • the feature mix;
  • one line per wave, e.g. W3: 14T 6S 1B (gap 15).

11. Checks

The checks list runs the game's own start-up checks on the map as you edit, plus figures for the designer. Click an entry to select what it's about.

Severities:

  • error: must be fixed.
  • warn: worth a look.
  • info and ok: figures that pass.
GroupWhat it checks
Map fileThe file's shape:
  • 1 to 4 lanes with different ids (letters and digits);
  • 1 to 6 sectors with different names;
  • valid pins, jitter and rules.
CandidatesEach spot's clearance from corridors, its spacing, staying on screen, reaching a lane, and staying out from under the HUD's level name, boss bar and wave preview.
ZonesSpots per zone against its quota, pins the quotas can't honour, and the feature mix against the resource spots.
Lanes
  • Each lane's length, and unopposed travel time for the slowest and fastest ground enemies in the waves.
  • Its length against LANE_LENGTH_FACTOR, and that it ends on the melee ring.
  • The spots in turret range of it, and the corridor width against the waves' bosses.
  • Whether the zone quotas give enough turret slots for every lane (lanes × turret slots per lane), and whether the sheet's lanes tab matches.
WavesSpawn rows that name a lane the level doesn't have (an error), unknown enemy types, counts and times.
PrepThese figures come from 50 layouts rolled as the game rolls them, run a second after the map is still (a "checking…" marker shows):
  • the feature route;
  • how often no fair draw is found at the level's stepBudget;
  • the share of single draws that fit the route band;
  • the turret slots typically covering each lane;
  • a suggested step budget.
DecorationObjects reaching into a corridor or a spot's area (all are marked on the map), and palette colours the decoration needs.

12. Preview, Play and Generate draft

  • Preview a run: rolls the layout with a seed, as the game would: slot pads, resource spots, the reroll count. Previous seed and Next seed step through seeds, and the preview follows every edit.
  • Play this level: opens the game at this level's Prep in a new tab, using the saved file (it asks you to save first). Tick "debug resources" to start with the debug resource grant. Go back by switching to the editor tab. After saving more changes, refresh the game tab.
  • Generate draft: replaces every layer, or one layer (lanes, spots, decoration or mire), with a seeded draft. It always asks first and is one undo step. Decoration drafts keep the landmarks.
    • Lanes: reroutes the level's lanes, whatever their number, from their entry points.
    • Every layer of a new level: takes 1 to 4 lanes from the sheet's lanes tab (three default lanes if it has none), and arranges the map's sectors (3 unless you changed the count) round them.
    • Spots: fills each zone's quota plus one spare. If some zones come out short (likely with one or two lanes, where some sectors have no lane in turret range), the status line lists them. Try fewer sectors or another seed.

13. What lives in the sheet

The editor never writes the CSVs. These stay in the Google Sheet:

  • levels tab: stepBudget, feature mix, enemyHpMult, stuckTime and region.
  • waves and spawns tabs: which lane each spawn uses. random spreads a type's entries over all the lanes as evenly as possible, so Bears go one per lane whatever the lane count.
  • globals: the default zone quotas and rules.
  • lanes tab: the lane ids the spawns drop-down offers.

After changing lanes, update spawns and lanes in the sheet, then pull it into data/.
